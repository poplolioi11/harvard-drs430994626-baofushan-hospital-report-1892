# 保福山聖教醫館略述十七編

《保福山聖教醫館略述十七編》刊於清光緒年間，記錄福州保福山聖教醫館的病例分類、來診統計、捐輸與院務。卷末列出當時流通的西醫書籍，可供教會醫療史、財務史與出版史比較。

This 1892 annual report from the Baofushan Christian Hospital in Fuzhou records historical patient statistics, hospital accounts, donations, and a list of medical books in circulation.

- 原刊由保福山聖教醫館編纂，1892 年刊於福州。共 24 幅，依底本分幅定位。 [館藏／原件](https://id.lib.harvard.edu/alma/990103927690203941/catalog)
